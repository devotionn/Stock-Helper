# 股票分析助手（Stock Helper）产品文档

> 版本：1.0 ｜ 日期：2026-07-29 ｜ 适用范围：一期开发

---

## 一、产品概述

**股票分析助手（Stock Helper）** 是一个运行在本地电脑上的股票信息整理与 AI 分析工具。

系统采用本地 Web 网页形式，用户点击桌面快捷方式后在浏览器中打开使用。

产品核心能力为五个字：**录入、上传、组合、分析、复盘**。

- **录入**：客户手动录入文字资料
- **上传**：上传 K 线图、分时图、新闻截图等图片
- **组合**：从 12 个模块中自由选择并排列组合
- **分析**：调用多模态 AI 对所选模块进行分析
- **复盘**：保存历史分析，支持后续复盘与改进

**重要定位说明：**

本系统**不是**自动炒股系统，**不是**量化交易系统，**不连接**券商账户，**不自动买卖**股票，**不自动执行**交易。它只是一个辅助客户整理信息、辅助思考的工具，最终判断由客户本人作出。

---

## 二、项目背景

客户是一位 60 多岁的股票投资者，电脑操作能力一般，主要依靠手动收集、整理和录入信息。

客户日常使用两台电脑：

| 电脑       | 用途                                                                                   |
| ---------- | -------------------------------------------------------------------------------------- |
| 第一台电脑 | 查看股票软件、财经信息、专家观点、技术分析、新闻和图片，由客户自己整理资料             |
| 第二台电脑 | 安装"股票分析助手"系统，将第一台电脑整理好的文字、截图、K 线图、新闻图片等内容手动录入 |

客户将第一台电脑整理好的内容，手动录入第二台电脑的系统中。系统主要在第二台电脑本地运行，数据保存在本地。

## 三、目标用户

### 3.1 用户画像

- 年龄：60 岁左右
- 电脑操作能力：一般，能进行基本点击、输入、复制粘贴，但不熟悉复杂操作
- 使用习惯：主要依靠鼠标点击，少量键盘输入
- 视力情况：需要较大字体和清晰对比
- 学习能力：不愿意学习复杂软件，希望上手即用

### 3.2 核心设计原则

面向该用户群体，产品必须符合以下要求：

1. 页面简单直观
2. 字体较大
3. 按钮较大
4. 操作步骤少
5. 不使用复杂菜单
6. 不设置过多专业选项
7. 重要按钮有清晰文字说明
8. 删除内容前进行确认
9. 数据自动保存或提供明显的保存按钮
10. 尽量减少用户学习成本

## 四、用户使用流程

### 4.1 日常使用主流程

```
启动系统
   ↓
工作台首页（看到 12 个模块格子）
   ↓
点击某个模块 → 进入模块编辑页面
   ↓
录入文字 / 粘贴文字 / 上传图片 / 粘贴截图
   ↓
保存
   ↓
返回首页，继续录入其他模块
   ↓
进入组合分析页面
   ↓
选择模块 → 调整顺序 → 填写分析要求
   ↓
点击"开始分析"
   ↓
查看 AI 分析结果
   ↓
保存到历史记录 / 保存到 AI 复盘 / 保存到操作建议
   ↓
日后进入历史记录页面查看复盘
```

### 4.2 复盘流程

```
打开历史记录页面
   ↓
查看某次历史分析
   ↓
对比当时判断与后来实际走势
   ↓
在"AI 复盘"模块中记录复盘内容
   ↓
在"操作建议"模块中调整操作参考
```

## 五、产品功能结构

### 5.1 功能总览

```
股票分析助手
├── 工作台首页（12 个模块展示）
├── 模块编辑（文字录入 + 图片管理）
├── 组合分析（模块选择 + 顺序排列 + AI 分析）
├── 分析结果展示
├── 历史记录（查询 + 查看 + 再次分析）
└── 系统设置（AI 接口 + 备份 + 显示设置）
```

### 5.2 功能关系

- 工作台首页是入口，展示所有模块状态
- 每个模块可独立编辑和保存
- 组合分析读取多个模块内容，调用 AI 生成结果
- 分析结果可保存到历史记录、AI 复盘、操作建议
- 历史记录可再次查看和再次分析

## 六、12 个模块说明

系统首页以 12 个格子的形式展示模块。每个模块都可以单独打开、编辑和保存。

| 编号 | 模块名称   | 主要用途                                 |
| :--: | ---------- | ---------------------------------------- |
|  0   | 一周策略   | 本周整体操作思路、仓位安排、重点关注方向 |
|  1   | 股票1      | 第一只关注股票的相关资料                 |
|  2   | 股票2      | 第二只关注股票的相关资料                 |
|  3   | 股票3      | 第三只关注股票的相关资料                 |
|  4   | 股票4      | 第四只关注股票的相关资料                 |
|  5   | 技术派观点 | 技术分析相关观点、指标解读、图形分析     |
|  6   | 钱说观点   | 特定信息来源的观点记录                   |
|  7   | 大盘走势   | 大盘指数走势、宏观市场情况               |
|  8   | 反向操作   | 反向思维、风险提示、对立观点             |
|  9   | AI 复盘    | 保存历史分析后的复盘内容                 |
|  10  | 行业板块   | 行业和板块相关资料                       |
|  11  | 操作建议   | 保存 AI 生成或客户修改后的操作参考       |

### 模块说明补充

- **股票1~4**：用于记录单只股票的文字资料和图片（K 线图、分时图、新闻截图等）。股票名称由客户自行填写，方便历史记录按股票名称查询。
- **AI 复盘（9号）**：用于保存历史分析后的复盘内容，例如原来的判断、实际走势、正确与错误的判断、错误原因、下次如何改进。既可保存 AI 生成结果，也允许客户手动修改。
- **操作建议（11号）**：用于保存操作参考，例如继续观察、等待确认、控制仓位、暂不参与、注意风险、达到某个条件后再考虑操作。既可保存 AI 生成结果，也允许客户手动修改。

2. 模块名称

- 所有删除操作均需二次确认

## 八、自定义组合分析逻辑

### 8.1 组合选择规则

客户录入资料后，可以从 12 个模块中自由选择多个模块进行 AI 分析。

**组合必须保留客户的选择顺序。**

示例 1：

```
0 -> 1 -> 7 -> 8
代表：一周策略 -> 股票1 -> 大盘走势 -> 反向操作
```

示例 2：

```
2 -> 6 -> 5 -> 7
代表：股票2 -> 钱说观点 -> 技术派观点 -> 大盘走势
```

### 8.2 组合操作功能

系统需要支持以下操作：

| 序号 | 功能               | 说明                         |
| :--: | ------------------ | ---------------------------- |
|  1   | 点击模块进行选择   | 点击模块卡片即加入组合       |
|  2   | 显示模块的选择顺序 | 已选模块按顺序排列，显示序号 |
|  3   | 调整模块顺序       | 支持上移 / 下移调整顺序      |
|  4   | 删除已选择模块     | 从组合中移除某个模块         |
|  5   | 清空全部选择       | 一键清空当前组合             |
|  6   | 保存常用组合       | 为常用组合命名并保存         |
|  7   | 一键使用常用组合   | 点击已保存的组合直接载入     |
|  8   | 填写本次分析要求   | 提供文本框填写本次分析重点   |
|  9   | 点击"开始分析"     | 启动 AI 分析                 |

### 8.3 组合顺序的意义

模块排列顺序会传递给 AI，作为分析上下文的逻辑顺序。例如"一周策略 -> 股票1 -> 大盘走势 -> 反向操作"代表从整体策略到个股、再到大盘、最后到风险对冲的思考顺序。

## 九、AI 分析逻辑

### 9.1 AI 需要读取的内容

AI 分析时需要读取所选模块中的：

1. 文字内容
2. 上传图片
3. 图片中的可识别信息
4. 模块名称
5. 模块排列顺序

### 9.2 AI 分析结果建议内容

AI 分析结果建议包括以下部分：

| 序号 | 分析项       | 说明                   |
| :--: | ------------ | ---------------------- |
|  1   | 信息汇总     | 将所选模块内容归纳整理 |
|  2   | 一致观点     | 各模块中相互印证的看法 |
|  3   | 冲突观点     | 各模块中相互矛盾的看法 |
|  4   | 关键判断     | 基于信息得出的核心结论 |
|  5   | 风险提示     | 潜在风险点             |
|  6   | 信息不足之处 | 哪些信息缺失或不够清晰 |
|  7   | 操作参考建议 | 笼统的操作方向参考     |

### 9.3 AI 使用规范（重要）

1. **不得虚构**股票价格、政策、财务数据或图片中看不清的信息
2. 当图片不清楚或信息不足时，要**明确提示无法确认**
3. AI 分析只作为**辅助参考**，最终判断由客户本人作出
4. 分析结果页面需在显眼位置标注"本分析仅供参考，不构成投资建议"

## 十、AI 复盘和操作建议逻辑

### 10.1 AI 复盘（9号模块）

9号"AI 复盘"主要用于保存历史分析后的复盘内容，内容包括：

1. 原来的判断是什么
2. 后来实际走势如何
3. 哪些判断正确
4. 哪些判断错误
5. 错误原因
6. 下次如何改进

**该模块既可保存 AI 生成结果，也允许客户手动修改。**

### 10.2 操作建议（11号模块）

11号"操作建议"主要用于保存 AI 生成或客户修改后的操作参考，例如：

1. 继续观察
2. 等待确认
3. 控制仓位
4. 暂不参与
5. 注意风险
6. 达到某个条件后再考虑操作

**该模块既可保存 AI 生成结果，也允许客户手动修改。**

### 10.3 与历史记录的关系

- 每次组合分析完成后，分析结果可保存到历史记录
- 客户可选择是否将分析结果保存到"AI 复盘"和"操作建议"模块
- "AI 复盘"和"操作建议"模块的内容会随客户修改而更新，同时历史记录中保留当时的原始版本

## 十一、历史记录功能

### 11.1 历史记录内容

每次组合分析完成后，需要保存历史记录。历史记录至少包括：

| 序号 | 记录项             |
| :--: | ------------------ |
|  1   | 分析日期和时间     |
|  2   | 使用的模块         |
|  3   | 模块组合顺序       |
|  4   | 当时的文字内容     |
|  5   | 当时上传的图片     |
|  6   | AI 分析结果        |
|  7   | 客户备注           |
|  8   | 后续复盘           |
|  9   | 是否保存到 AI 复盘 |
|  10  | 是否保存到操作建议 |

### 11.2 历史记录查询

历史记录支持按照以下条件查询：

1. 日期
2. 组合名称
3. 股票名称
4. 模块编号
5. 关键词

### 11.3 历史记录操作

- 支持再次查看某条历史记录的完整内容
- 支持基于历史记录再次发起分析
- 历史记录不可删除（防止误删重要复盘资料），如需删除需特别确认

## 十三、数据保存与备份

### 13.1 数据保存方式

数据主要保存在第二台电脑本地。

| 数据类型                               | 保存方式      |
| -------------------------------------- | ------------- |
| 文字内容、模块信息、组合配置、历史记录 | SQLite 数据库 |

| AI 分析结果                            | SQLite 数据库 |

### 13.2 备份功能

系统需要提供简单的数据备份功能，备份内容包括：

1. 数据库
2. 上传图片
3. 历史分析结果
4. 常用组合配置

备份操作要求：

- 提供明显的"一键备份"按钮
- 备份位置可在系统设置中配置
- 备份文件以日期命名，便于识别
- 备份完成后提示成功

| 启动方式 | 桌面快捷方式一键启动           |

## 附：开发注意事项

1. **用户是 60 岁投资者**，所有设计以"简单、直观、大字、大按钮"为第一原则。
2. **避免过度设计**，不添加客户未提出的功能，不引入复杂架构。
3. **AI 是辅助工具**，必须明确标注仅供参考，且不得虚构信息。
4. **数据安全第一**，所有删除需确认，历史记录建议不可轻易删除。
5. **本地优先**，一期所有数据与运行均在本地，不依赖云端。
6. **可维护性**，代码结构清晰，便于后续二期扩展。
